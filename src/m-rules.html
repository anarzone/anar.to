      How it decides: the real loop, from Expadu's Applicability.php
      
    foreach ($appliesIf as $group) {
    $verdict = self::evaluateGroup($group, $attributes);
    if ($verdict === self::Yes) { return self::Yes; }
    if ($verdict === self::Unknown) { $sawUnknown = true; }
}
return $sawUnknown ? self::Unknown : self::No;
    
      
    A rule is a list of condition groups. Inside a group every condition must hold; any one group is enough. A fact nobody has asked yet is null, which makes the group unknown instead of false. Unknown rules turn into the questions above. Rules never create facts, so the order you answer in never changes the result.
